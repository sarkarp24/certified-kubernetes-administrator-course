What is the kubernetes filter doing?

The kubernetes filter enriches logs.

Before it runs:

{
  "log": "GET /index.html 200"
}

After it runs:

{
  "log": "GET /index.html 200",
  "kubernetes": {
    "namespace_name": "default",
    "pod_name": "nginx-xyz"
  }
}


Fluent Bit pipeline
INPUT → FILTER → OUTPUT

This order is not configurable

Stage	Purpose
INPUT	Read logs (files, containers)
FILTER	Modify / enrich / drop logs
OUTPUT	Send logs to destination (Elasticsearch)
